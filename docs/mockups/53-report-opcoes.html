Por que virar a matriz?
  • Nome de etapa é longo e são até 29; praças são poucas. Linha cresce para baixo com rolagem natural, coluna não.
  • Cada área usa um conjunto diferente de etapas: com "só com movimento", a matriz mostra só as etapas que existem no filtro.
  • Os títulos de grupo entre as linhas mantêm a leitura macro sem esconder as etapas.
Alternativa (se preferir manter praças nas linhas)
  • Etapas nas colunas, com rolagem lateral e a 1ª coluna fixa.
  • Funciona bem quando há filtro de esteira (poucas etapas), mas sem filtro vira uma tabela larga com 20+ colunas.
  • Nos dois casos o visual precisa de uma versão nova (Matriz de calor 1.3.0): títulos de grupo, botão Etapa | Grupo.

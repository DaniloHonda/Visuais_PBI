Como se chega aqui: cada gráfico do Resumo e do Report ganha o botão "Ver aplicações ↗" no canto. Ele abre esta página já na visão daquele gráfico, com a barra de filtros sincronizada (período, especialidade, etapa…). Clique direito → Detalhar continua funcionando para levar o ponto exato clicado (ex.: um motivo).

Cada visão tem as suas colunas: Rejeitados e motivos → etapa da rejeição, motivo, tipo · Andamento por faixa → etapa atual, dias parado, faixa · SLA por etapa → uma linha por passagem (entrada, saída, dias, resultado: aprovada / rejeitada / voltou) · Contratadas → origem (direto / via pool), início do ciclo, SLA · Entrevistas → uma linha por entrevista, quem marcou, data.

O número do topo confere com o gráfico (✓). Se não conferir, o selo mostra a diferença e o motivo (ex.: rejeitadas em etapa sem nome).
